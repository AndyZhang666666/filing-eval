# 一页 PRD — 公告摘要事实一致性评测

> ⚠️ 标记的是需要 Andy 本人确认的判断。这些判断的答案必须来自他，不能由我代填。

## 用户

投研 / 合规团队里负责「把 AI 摘要放出去」的那个人。他不写 prompt，不看代码，但他要对摘要里的每一个数字负责。

## 痛点

AI 摘要看起来很专业，所以读的人不会逐字核对。而摘要最常见的三类错误 —— 数字量级、方向、主体 —— 都不会让文本看起来"不对劲"。一旦放出去被引用进研报，追责在他。

## 要做的事

给摘要生成系统装一个**回归测试**：每次改 prompt / 换模型，跑一遍金标集，三个数字不能掉。

## 三个数字

| | 定义 | 为什么是这个 |
|---|---|---|
| 错误检出率 | 错误样本里，该报的错报出来了的比例 | 查错工具的核心价值 |
| 误报率 | 干净样本里，没错却报了错的比例 | 查错工具的可信度代价，与上面方向相反 |
| 覆盖率 | 原文里 `high` 重要度的硬信息，摘要带上了多少 | 幻觉率 0 的摘要也可能不能外发 |

**不合成一个分数。** ⚠️ Andy 需要确认：这三个是不是业务上真正关心的三个？有没有第四个（比如「措辞是否中性」）？

## 断言分类

- **写错**（contradicted，权重 1.0）：原文有对应信息，摘要与之矛盾
- **无据**（unsupported，权重 0.8）：原文里找不到依据，摘要自己补的
- 有据 / 无法核验：不计入

⚠️ Andy 需要确认：写错 > 无据 这个排序对不对？在他的业务场景里，编造归因（"得益于跨境业务放量"）和数字写错，哪个后果更重？

## 关键信息类型（决定覆盖率分母）

金额 / 比例 / 方向 / 主体 / 时间 / 风险。只算 `high`。

⚠️ Andy 需要确认：`importance` 的口径 —— 「省略这条，读者对交易的理解会出错」算 high。这个定义他认不认？

## 金标集

- 主集 20 条：4 干净 / 11 错误（5 写错 + 4 无据 + 2 遗漏）/ 5 边缘
- 困难集 8 条：逻辑型错误（范围 / 因果 / 情态 / 基数 / 主体 / 实质遗漏）+ 2 条刻意像有问题的干净样本
- 全部虚构公司，无真实数据

⚠️ **Andy 必须逐条过一遍 `expect`。** 尤其：
- f08（担保方倒置）、h05（子公司 vs 公司）这类主体错误，在他的口径里算不算错
- f14「经营状况良好」在净利润下滑时算不算无据
- h07「最高不超过」vs「不超过」是否真的等价

## 非目标

- 不做摘要生成，只做核验
- 不做多语言
- 不做 PDF 解析，输入是纯文本

## 两周内能交付的

- [x] 裁判 + 金标集 + 三个指标
- [x] 稳定性 / 对抗 / 困难集
- [x] 可点开的核验台，错误定位到字
- [ ] Andy 复核标注
- [ ] 跨模型对比（至少 2 个裁判）
- [ ] 部署
