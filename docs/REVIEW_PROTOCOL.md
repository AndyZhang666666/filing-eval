# 从回放到可验证的核验工具

## 本轮事实

- `demo/` 为独立静态工作区，可部署到 GitHub Pages；原 Next.js 应用和 API 保留，未改成伪实时服务。
- `scripts/build-demo.mjs` 将 28 条公开模拟公告与已有历史输出按 ID 对齐，不重新调用模型。
- 浏览器复核按数据版本保存，本地导出包含历史原判、复核结论、理由和时间；不会改金标、不会回流到公开仓库。
- 原预期标签没有完成独立人工复核。本轮的源引文完整性检查不是人工标注，也不是正确性证明。

## 复核要求

逐条检查：数字/单位、主体、期间、拟/已、因果、重要遗漏。可以同意、提出修正、保留争议。不同意或争议必须给依据。引句不能逐字定位时不自动认定成立，原文未支持不等于现实必假。

h05：对子公司与母公司的简写，合并口径与披露主体可能给出不同判断。继续从检出率分母排除，直到约定适用范围；不能改标签迁就裁判。

## 下一轮独立验证

`data/review-holdout.json` 的 6 条候选样本为新构造对照，不含任何真实公司资料。由开发助手起草，未独立人工复核、未调用模型、未用于调参，不能称为新增通过样本。

1. 独立复核人先确认原文、预期、重要性口径和争议裁决。
2. 冻结规则、模型版本、样本与判分逻辑；保留与调参集的隔离。
3. 取得模型调用授权后运行，分别报告检出、误报、覆盖和争议，不只给总分。
4. 失败实例回到问题定位；新一轮调参后应另保留未见测试，不能反复使用同一留出集再声称独立。

## 数据与隐私

公开演示只读取本目录静态数据。访客复核文字可能含个人信息，默认不上传；清理浏览器数据会失去本地记录，重要记录请导出。导出不代表审核通过或获得任何投资建议。
